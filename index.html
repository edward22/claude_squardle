Fill grid from a screenshot (OCR)

Set rows/cols above to match the screenshot first. Paste an image (click the box below, then Ctrl/Cmd+V), drop one on it, or upload it. Drag the crop handles so the box tightly covers just the letter grid — no extra UI around it — then run OCR. Mostly-blank cells are auto-detected as holes. OCR needs an internet connection the first time (it downloads the recognition engine), and the result is never perfect, so review the grid before solving.
